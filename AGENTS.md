# Code readability

For every task that creates, modifies, or refactors code in this repository, and
for generated source-code examples, read and apply
[plain-language-code-comments](skills/plain-language-code-comments/SKILL.md).
Use it together with other skills relevant to the task. Comments should explain
purpose, flow, and important decisions in language a non-coder can understand;
avoid redundant comments on obvious lines. Review and update affected comments
before finishing a code change. Explicit user instructions take precedence.
